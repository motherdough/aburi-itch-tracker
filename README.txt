HOW TO USE ON YOUR PHONE
1. Host this folder on any HTTPS static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.).
2. Open the hosted URL in Safari/Chrome.
3. iPhone: Share -> Add to Home Screen.
   Android: browser menu -> Install app / Add to Home screen.
4. The app works offline after the first load.

DATA
- Daily entries are stored locally in the browser.
- Photos are stored in IndexedDB on the device.
- Use "Backup data" regularly. Clearing browser/site data can erase local entries/photos.
- "Export CSV" gives a vet-friendly log without photo files.

This prototype does not sync across devices or send reminders.
